# lineage.txt

The people whose code subtract depends on.

---

## Brian Fox — the substrate author

Announced bash as a beta in June 1989 (Fox 1989a). Primary maintainer
until early 1993, when Chet Ramey took over. Authored the readline
library (Fox 1989b), the history library (Fox 1989c), and GNU Info.

Three things Fox wrote that subtract depends on directly:

**bash itself.** The dispatcher. `command_not_found_handle`. `case`.
Parameter expansion. Process substitution. Every tier of subtract's
routing is a bash construct Fox authored. subtract is GPLv2 — the same license as the Linux kernel.

**readline** (Fox 1989b). Tab completion, `Ctrl-R` history search,
line editing. When T0 consults `compgen` for a completion candidate,
the reason `compgen` has anything to say is that Fox made completion
a first-class shell primitive in 1989.

**the history library** (Fox 1989c). `!!`, `!$`, `Ctrl-R`, `HISTFILE`.
Episodic memory for the shell, shipped in 1989, present in every bash
install since.

## Chet Ramey — the substrate steward

Took over bash maintenance from Fox in 1993 and has held the seat
for thirty-three years. Authored `help` as a builtin in the form
subtract's T0.5 tier consults (`help -m`, `help -s`). Kept
`command_not_found_handle` a stable public hook rather than letting
it become an implementation detail.

**coproc** (Ramey, bash 4.0, 2009). Bidirectional pipe between the
shell and a background process, exposed as file descriptors. subtract
uses coproc to hold a loaded model in memory and talk to it through
stdin/stdout — inference as a Unix filter. The concept is David Korn's
(ksh88, 1988); Ramey brought it to bash.

Fox wrote the substrate. Ramey kept it reachable. subtract needs both.

## David Korn — coprocesses

Wrote ksh at AT&T Bell Labs. Released ksh88 in 1988 with coprocesses:
a background process connected to the shell via bidirectional pipes,
addressed through `|&`, `print -p`, and `read -p`. The idea that a shell could hold
a long-running conversation with a subprocess — not just pipe output
through it — originated here.

Ramey reimplemented the concept as `coproc` in bash 4.0 (2009). subtract
depends on the bash form, but the design is Korn's.

## Doug McIlroy — pipes

Proposed the pipe primitive in a written memo (October 11, 1964).
Ken Thompson implemented it in Unix V3 in February 1973. Every tier
of subtract's routing chain — T0 through T4 — composes through pipes.
Named pipes (FIFOs), which subtract uses to connect hosuni to
parsimony across process boundaries, are the filesystem-visible
extension of McIlroy's original idea. Documented in Ritchie 1984.
