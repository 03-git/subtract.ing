NATIVE TOOLS VS PRIMITIVES

RESULT
       9 Claude Code features tested against Unix primitives.
       2 primitive wins, 1 feature justified, 1 marginally justified,
       1 invalidated, 1 not justified, 2 blocked, 1 not tested.

       Of the 6 resolved features, all wrap IPC, timers, or diff.
       Wrappers add LLM judgment at the cost of determinism and
       auditability. LLM judgment is net positive for semantic
       tasks (simplify) and net negative for deterministic tasks
       (loop, mcp).

       Feature       Finding                 Primitive
       -------       -------                 ---------
       effort        INVALIDATED             --model flag
       mcp           PRIMITIVE WINS          llama-server tool API
       loop          PRIMITIVE WINS          while/sleep
       skills        NOT JUSTIFIED           cat + CLAUDE.md
       review        MARGINALLY JUSTIFIED    diff + grep
       simplify      FEATURE JUSTIFIED       xargs -P + grep
       compact       BLOCKED                 session discipline
       multi-session NOT TESTED              tmux
       routines      BLOCKED                 crontab

EFFORT: INVALIDATED
       /effort adjusts reasoning depth within the same model. Does not
       change which model runs. The spec assumed it routed to different
       tiers. It does not. Model routing via --model flag achieves the
       intended behavior directly.

MCP: PRIMITIVE WINS
       llama-server exposes OpenAI-compatible tool-calling API with
       built-in tools: read_file, write_file, edit_file, apply_diff,
       file_glob_search, grep_search, exec_shell_command.

       qwen3-32b successfully chains 3-step tool sequences via
       llama-server's native API. Note: this comparison tests
       llama-server tool-calling vs MCP as a transport, not
       Claude Code tool-calling quality. MCP is JSON-RPC wrapper
       around capability llama-server already has.

LOOP: PRIMITIVE WINS
       /loop charges 1800 tokens/min with 60s minimum interval.
       while/sleep costs 0 tokens, any interval, full log preserved.

       Primitive: 0 tokens, any interval, sovereign.
       Feature: 1800 tokens/min, 60s min, state in platform.

SKILLS: NOT JUSTIFIED
       Skills are markdown files. cat works on them. Glob finds them
       in 0.02s. The feature adds indirection without capability gain.

REVIEW: MARGINALLY JUSTIFIED
       git diff + grep catches most issues. Feature catches quoting
       bugs in shell scripts that grep cannot express. Justified for
       shell scripts. Primitive sufficient for simple diffs.

SIMPLIFY: FEATURE JUSTIFIED
       grep/sed miss semantic patterns (loop-to-reduce, dead code,
       function reuse). Feature caught them, 60% line reduction,
       0 human minutes vs 8. Feature justified.

METHOD
       Controlled comparison on Rousseau (M1 Max Studio 64GB).
       Each feature tested against its Unix primitive equivalent.
       Measured: tokens, wall time, human effort, quality score.
