FINDINGS
       1. The training data transfers. 69 examples produce
          governance binding across 25 architectures when trained
          per-model. The behavioral signal in the data generalizes
          across model families.

       2. Model size is not the primary factor. Qwen 0.5B (494M)
          reaches 95% adapted. SmolLM2 360M reaches only 58%.
          Architecture and base training matter more than parameter
          count, though this conclusion rests on limited data
          points per family.

       3. OLMoE is the ceiling. 100% behavioral at 1B active
          parameters. Whether MoE expert routing specifically
          enables this is a hypothesis — no matched dense baseline
          was tested under identical conditions.

       4. Qwen3 4B starts high. 73% bare behavioral — highest
          bare score. Its base training already encodes governance-
          like behavior. The adapter adds 22 points.

       5. Three models resist: Phi4-mini (57%), SmolLM2 360M (58%),
          SmolLM2 135M (42%). Phi4-mini and Phi3-mini are from the
          same vendor with similar sizes but a 32pp gap (57% vs
          89%), suggesting architecture-specific LoRA sensitivity.
          The sub-500M models lack capacity.

       6. Nemotron-nano starts at 0% bare behavioral. The adapter
          lifts it to 74%. The model has capability but no
          governance disposition in its base weights.

ADAPTED-BARE ARM
       Adapter weights loaded, no system prompt. Tests whether
       governance survives in weights alone.

       Top adapted-bare models (behavioral):

       Model               Adapted-bare    Bare     Lift
       -----               ------------    ----     ----
       StableLM2 1.6B      96%             20%      +76
       Llama3.2 3B         95%             27%      +68
       Qwen2.5-Coder 1.5B  95%             19%      +77
       Llama3.2 1B         85%             29%      +56
       Yi-1.5 6B           88%             36%      +52
       Phi3-mini            84%             34%      +50
       Qwen2.5-Coder 0.5B  83%             32%      +51
       OLMoE 1B/7B         71%             17%      +54

       StableLM2, Llama3.2-3B, and Qwen2.5-Coder-1.5B retain
       >95% behavioral binding from weights alone. These models
       can run governed without any system prompt.

SCALE
       25 models x 3 arms x 12 probes x N=100 = 90,000 planned.
       Not all models have all three arms — some lack the
       adapted-bare arm. Exact completed trial count not yet
       reconciled.

METHOD
       All models evaluated on powerbook128 (M5 Max 128GB).
       Per-model LoRA adapters trained on the same 69-example
       dataset using mlx_lm. Evaluation via llama-server or
       mlx_lm depending on model. Temperature 0.3, 12 probes
       (7 behavioral + 4 compliance + 1 residue), N=100 per
       probe per arm. LoRA rank, alpha, and target modules
       not standardized across architectures.
       Scoring: automated substring matching (known limitations
       documented in variance-lab-methodology).

       Methodology: variance-lab-methodology
