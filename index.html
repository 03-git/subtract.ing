NAME
       subtract.ing — variance-lab findings from empirical local LLM measurement

SYNOPSIS
       curl -s https://subtract.ing/findings.md | while IFS=$'\t' read slug title summary kw; do
           echo "$slug: $title"; done

DESCRIPTION
       Findings from 135,000+ inferences across 40+ models. Each finding states
       what was tested, what was measured, and what the data showed. No theory
       without data. No data without method.

       findings.md is the manifest. TSV: slug, title, summary, keywords.
       Each finding page has visible frontmatter as first bytes on the wire.
